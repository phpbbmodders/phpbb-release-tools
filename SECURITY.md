# Security Policy

## Supported versions

Only the latest version on the `main` branch is supported.

## Reporting a vulnerability

Please report security problems by email to **board@phpbbmodders.com**. Do not open a public issue.

In your report, please give:

- the organization name: **phpbbmodders**
- the project name: **phpbb-release-tools**
- what the problem is and how to reproduce it
